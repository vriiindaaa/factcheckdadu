# Overview

The Citation Intelligence Dashboard is a proposed GEO (Generative Engine Optimization) product feature designed to help brands track and improve their visibility across AI-powered search platforms such as:

- ChatGPT
- Perplexity
- Gemini
- Claude
- Grok
- Llama
- Mistral

As AI-generated answers increasingly replace traditional search results, brands are losing visibility without knowing where or why. This dashboard aims to solve that problem by providing measurable AI citation analytics.

---

# Problem Statement

AI search is rapidly changing user discovery behavior.

### Current Challenges

- 40%+ of Google searches now generate AI summaries or zero-click answers
- Brands are frequently cited in LLM outputs without visibility into performance
- Existing SEO tools focus only on traditional search rankings
- No industry-standard solution exists for measuring AI citation visibility

This creates a major analytics gap for modern marketing teams.

---

# Proposed Solution

## Citation Intelligence Dashboard

A unified dashboard that tracks how brands appear across AI-generated responses.

### Core Features

#### 1. LLM Share of Voice Score
Measures the percentage of AI-generated responses mentioning a brand versus competitors.

#### 2. Citation Sentiment Tracker
Analyzes whether brand mentions are:
- Positive
- Neutral
- Negative

#### 3. Prompt Coverage Map
Identifies which buyer-intent prompts trigger brand mentions across LLMs.

#### 4. Citation Source Audit
Tracks which content assets are being used by AI systems:
- Blogs
- PR articles
- Documentation
- Landing pages
